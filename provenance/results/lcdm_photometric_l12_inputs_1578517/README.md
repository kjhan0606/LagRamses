# Initial-condition inputs for the NGC 2403 ΛCDM comparison

The primary target is halo 434. Halo 451 is the backup. Both come from the same periodic 25 Mpc/h parent box. The selection used the halo mass inferred from NGC 2403 photometry, independently of its rotation curve. [Selection, particle identities, and maps](../lcdm_photometric_zoom_1578501/README.md)

Each candidate directory contains a MUSIC configuration and its traced region in parent-box coordinates. The configurations specify gas and collisionless CDM at redshift 49, first-order displacements, levels 8 through 12, and a common random seed at each level. Paths resolve from the individual candidate directory. Both configurations select the same fine-sampled transfer table. The code revision is in `code_revision.txt`. Grammar job 1578517 prepares the input specifications and tables. Generating the three-dimensional fields is a separate step.

CAMB 1.6.5 computes the linear GR transfer functions for the parent cosmology with Ωm = 0.315, Ωb = 0.0493017, h = 0.6736, and massless neutrinos. The two sampling settings are 100 and 200 per log interval. The comparison covers the fundamental mode through the diagonal Nyquist frequency of the level-12 grid, including separate tests of gas and CDM velocities. In the common frequency range we also compare against the original parent transfer table at its tabulated frequencies. The reported statistic is the relative L2 difference in each band. [Checks by field and wavenumber](transfer_checks.csv)

The fine table reaches 1,525.20 h/Mpc. The most demanding mode in the level-12 grid lies at 891.52 h/Mpc. Across the five fields, the largest bandwise relative L2 difference between samplings is 0.0002804%, in the gas density. Against the original nodes it is 0.0000307%, in the gas velocity. Both fall below the 1% acceptance threshold. These results test the input tables. Realized initial density and velocity spectra still require measurement.

At level 12 the CDM particle mass is 24,891 solar masses. If a fully refined halo retains the parent halo's enclosed total mass and the cosmic dark matter fraction, groups 434 and 451 would contain 5.47 and 5.50 million high-resolution CDM particles inside R200c. At level 11 the estimates fall to 0.684 and 0.687 million. The evolved run must measure the high-resolution particle count inside its own R200c, contamination by coarse particles, and force convergence at the observed radii. [Wavenumber coverage and particle budget](preparation.json)

The Group 434 generation script requests four CPU cores, 128 GiB memory, and three hours on Grammar. Its working-file budget is 96 GiB. Scaling the previously measured Group 205 level-11 IC and working-file size by eight gives a rough planning estimate of 39.4 GB; the different region geometry makes the actual size uncertain. The script writes a new job-specific directory and records the effective configuration. It generates initial conditions and diagnostics, without RAMSES evolution.

The prepared geometry and common-parent Fourier analyses were checked against the existing Group 205 data. Those data also show why the gas-density minimum must be examined for the new realization. [Reference test and limits](../lcdm_photo_audit_reference_1578549/README.md)

A separate comparison of the existing parent MUSIC input against a CAMB calculation with the matched cosmological parameters found approximately 1.9% less density power and 3.3% less velocity power in the high-k base-grid bands. The recorded MUSIC growth and velocity factors quantitatively account for the offset. This configuration keeps the parent normalization.
