## Native implementation and scientific scope

Opt-in `hhe_d03_maxent128_fs2010_v1`: positive128-node N/E reconstruction,
Verner H/He absorption, node FS2010 and actual D03 four-bin mass opacity.
Absorption is one competing H/He/grain event; grains are uncapped. Rejected
finite-inventory H/He packets retain E/N, without the fixed operator's
second dust-transfer sink. Elastic delta-isotropic survivor redistribution
is a subsequent node-wise split with normalized quadrature weights. It
preserves N/E but does not resolve multiple within-step scattering histories
or deliver relative-grain/gas radiation force.

Native actual grain energy enters the receiver's deposited-spectrum argument
and the existing material/IR transaction. Old group dust tau is zero and the
old primary scatter call is bypassed. Thus no fixed mean re-enters grain heat
and no second dust absorption occurs. Four temporary columns per cell and
immutable node arrays replace a persistent spectral tensor; checkpoint cell
width is unchanged for the same existing dust/IR build.

Requires DUST_LIVE1/CHIMES0 and D03 two-size DL01 material, radii.01/.1micron,
densities2.2/3.8. Rejects Fe/PAH/sublimation/relative dynamics, requires v4
scattering-enabled contract. Existing fixed/HHe64/FS64 modes stay unchanged.
No namelist key/meaning changed, so both generators remain untouched per the
plan's Q-LEAN disposition. Runtime guide updated.

Source: [Draine dielectric data](https://www.astro.princeton.edu/~draine/dust/dust.diel.html),
[Draine2003](https://arxiv.org/abs/astro-ph/0308251). Existing staged raw files
are reused. The separate `dust_d03_band_data.inc` is generated by the existing
Mie builder's `--band-nodes 128` branch. Original representative/IR include
and identity are untouched. Mie3.3.0/numpy2.3.3; material20K dielectric and
1/3--2/3 graphite remain approximations, not PAH or grain-photoelectron physics.
