# lagRamses-SIDM

This directory is the dedicated worktree for the self-interacting and
dissipative dark-matter project. It brings the simulation code, the Paper-I
Overleaf repository, the lightweight Lageunha run metadata, and the project
handoff under one local root.

The code worktree follows the local `sidm` branch of the LagRamses repository.
The paper remains an independent Git repository and is registered as the
`paper` submodule. Raw simulation outputs remain on Lageunha under
`/gpfs/kjhan/Hydro/Sidm`.

Start with `SIDM_HANDOFF.md`. The shorter `PROJECT_MEMO.md` records only the
immediate operating rules and next production task.
